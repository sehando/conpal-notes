# AWP 기반 자재·조달 연계

## 요약

- 조달을 "납품"과 "설계 입력(Vendor Data)"의 두 흐름으로 분리 관리
- 최초·최종 Delivery만 반영하던 구매 일정을 Tag·Lot별 현장 사용 가능 시점으로 상세화
- 출처 : [[원전 건설 AWP 적용 계획]], [[원전 건설 AWP 도입 계획]]의 해당 부분 발췌·재구성

## 1. 구매 Key Milestone 체인

```
PO → Vendor Drawing 1차 제출 → [Certified Vendor Data] → 제작 → FAT → 선적 → [현장 입고(ROS)] → 설치 가능
```

- 굵은 노드(대괄호) = 공정표 최소 필수 노드
- ROS를 공정표에서 역산해 발주자에게 공식 통보. 통보 이력 = 증빙
- 적용 순서 : 주공정 품목, Vendor Data 의존 품목 우선 (파레토 원칙)

## 2. Vendor Data Deliverable Register

| 필드 | 내용 |
|---|---|
| 식별 | PO·Tag·자료 ID |
| 연결 | 영향받는 EWP·CWP·Activity |
| 일정 | 공급업체 제출 약속일, 설계 필요 시점, 현재 예측일 |
| 상태 | 검토·재제출·사용 가능 |
| 책임 | 책임자, 승인 문서 |

- 자료 접수와 설계 사용 가능 판단의 분리
- 대상 정보 : 앵커볼트 배치·규격, 기기 하중·외형, 노즐 위치, 전력·단자, 배관·덕트·관통부 인터페이스

## 3. Tag·Lot별 사용 가능 상태

| 단계 | 상태 |
|---|---|
| 1 | Approved for Fabrication (제작 승인) |
| 2 | Fabrication·Inspection |
| 3 | Ready to Ship |
| 4 | Delivered to Site |
| 5 | Receiving Inspection·QA 문서 확인 |
| 6 | Allocated to IWP (사용 가능) |

- PO 분할 없이 PO 내 현장 사용 단위의 납품 그룹 정의 (예: A Zone 앵커·템플릿, B Zone 기기 본체·부속품)
- 본체 도착 ≠ 설치 가능. 부속품·품질문서 미비 시 실행 불가
- "구매 완료"와 "이번 IWP용 배정 완료"는 다른 상태

## 4. 기초 공사의 이중 경로

| 경로 | 구성 |
|---|---|
| 정보 경로 | 공급업체 선정 → 기초 인터페이스 자료 제출 → 설계 검토·사용 가능 판단 → 상세설계 반영 → 시공용 도면 발행 → IWP 준비 |
| 자재 경로 | 앵커·템플릿 사양 확정 → 제작·납품 → 검사·문서 확인 → 작업용 배정 |

설명용 예시 (달력일, 기타 조건 동일 가정)

| 구분 | 당초 | Vendor Data 20일 지연 |
|---|--:|--:|
| Vendor Data 사용 가능 | D40 | D60 |
| 정보 경로 준비 완료 (+55일) | D95 | D115 |
| 기타 선행조건 준비 완료 | D100 | D100 |
| 기초 작업 착수 | D100 | D115 |

- 착수 영향 = 20일이 아닌 15일. 준공 영향은 경로 임계성·여유에 따라 별도
